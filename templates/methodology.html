Architecture & Methodology

SIH25034 — Technical documentation of the PathMatch Multi-Agent LLM Engine.

1. Core Principle: Pure LLM Recommendation

Conventional recommendation systems rely on lexical keyword matching (TF-IDF, Bag-of-Words) or mathematical vector distance (Cosine similarity, Sentence Transformers). While simple, traditional methods fail to grasp transferable competencies, project context, or prerequisite dependencies.

Strictly Prohibited in Recommendation Engine:
  • TF-IDF & TfidfVectorizer
  • Cosine similarity calculations
  • Sentence Transformers & Embedding similarity
  • Random Forest, SVM, Logistic Regression
  • Traditional keyword-overlap ranking
  • Hardcoded weighted similarity formulas
Performed Exclusively by LLM Reasoning:
  • Natural-language profile and resume understanding
  • Skill extraction and normalization
  • Transferable skill identification without exaggeration
  • O*NET requirement interpretation
  • Semantic role suitability evaluation (6 dimensions)
  • Comparative role ranking, skill gaps & roadmaps

Python acts strictly as the orchestration layer: handling database retrieval, input sanitation, structured JSON validation, token tracking, and web persistence.

2. PathMatch Multi-Agent Architecture

Agent 1
Student Profile Understanding Agent

Converts unstructured student resumes and text into validated JSON, distinguishing explicit skills from project inferences without inventing proficiencies.

Agent 2
Skill Intelligence Agent

Classifies confirmed, related, transferable, and verification-required skills. Strictly prohibits related skills from becoming confirmed student skills.

Agent 3
Occupational Knowledge Retrieval Agent

Queries SQLite for relevant O*NET SOC records based on domains and tags. Passes candidate records as prompt context to prevent database flooding.

Agent 4
LLM Role Evaluation & Recommendation Agent

The core intelligence. Evaluates candidate occupations across 6 dimensions, synthesizes comparative match scores (0-100), and ranks top occupations.

Agent 5
Skill Gap Analysis Agent

Conducts comparative competency audits, highlighting missing essential tools, additional frameworks, and actionable improvement steps.

Agent 6 & 7
Roadmap & Career Assistant Agents

Agent 6 synthesizes 30-60-90 day milestone roadmaps with exercises and mini-projects. Agent 7 provides interactive conversational career guidance.

3. Six-Dimension Evaluation Rubric

Evaluation Dimension Target Weight Evaluation Criteria Handled by LLM
1. Required Skill Alignment ~30% Direct overlap between student confirmed skills and core occupational requirements in O*NET.
2. Transferable Skill Alignment ~20% Foundational capabilities (e.g. OOP, algorithmic problem solving) that facilitate rapid learning.
3. Project Relevance ~20% Verifiable practical implementation evidence demonstrated in student portfolio projects.
4. Interest Alignment ~15% Synergy between student declared career interests, stated goals, and daily occupational work activities.
5. Educational Suitability ~10% Compatibility of degree program and specialization with standard occupational entry requirements.
6. Experience Suitability ~5% Appropriateness of scope for college student internship or early-career placement.

4. Data Source Policy & Critical Clarifications

Important Policy: PathMatch AI recommends occupational role categories and career standards from the official O*NET database. It does NOT recommend verified live employer vacancies, nor does it display fictional hiring companies, fake salaries, or fabricated vacancies.

Match Score Interpretation: A match score of 88/100 represents an AI-generated comparative suitability ranking based on rubric evaluation. It is not a statistically validated probability of getting hired or a guarantee of employment.
